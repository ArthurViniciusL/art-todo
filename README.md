# Art Todo

A local, offline todo list for the desktop. Built with Electron, React, TypeScript and HeroUI.

Status: in development. See [docs/plan.md](docs/plan.md) for the roadmap.

## Development

```bash
pnpm install
pnpm dev
```

## Checks

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm test:e2e
```

## Build a .deb

```bash
pnpm build:linux
```

The package is written to `dist/`.
